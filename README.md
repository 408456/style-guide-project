# Руководство по стилю ГолосЛичный

Учебный проект по Docs as Code для лабораторной работы 3.
Исходники сайта находятся в docs. Команды сборки и правила изменений описаны в
[CONTRIBUTING](CONTRIBUTING.md).

## Публикация

В Settings / Pages выберите GitHub Actions. После успешного workflow на main
сайт будет доступен по адресу <https://408456.github.io/style-guide-project/>.
Наличие конфигурации не означает, что сайт уже опубликован.

## Объем

Страницы описывают стиль документации и целевое поведение проектируемого продукта.
Раздел доступности добавляется отдельным PR в рамках задания.
