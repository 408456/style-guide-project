# Доступность текста

Смысл должен быть понятен без цвета и картинки. У изображения указываем альтернативное описание его полезного содержания. Не пишем нажмите зеленую кнопку: называем кнопку. Ссылки понятны вне соседнего абзаца. Предупреждение ставим до опасного действия. Для удаления голоса сначала объясняем последствия. Проверяем чтение с клавиатуры, видимость фокуса и масштаб 200 процентов. Автоматическая проверка не заменяет ручную.
