# Структура страницы

Название описывает задачу. Далее идут назначение, условия перед началом, последовательность действий, ожидаемый результат и решение возможных проблем. Справка вместо шагов содержит определения и ограничения. У страницы один заголовок первого уровня; вложенные заголовки идут последовательно. Инструкция заканчивается наблюдаемым результатом, например: сообщение прозвучало один раз.
