# Markdown и примеры

Шаги оформляем нумерованным списком, независимые условия - маркированным. До и после списка оставляем пустую строку. У блока кода указываем язык. Ссылке даем понятное название, например Инструкция по подготовке записей. Таблицу используем для сравнения значений, а не для длинных объяснений. В примерах не публикуем реальные голоса, тексты общения и персональные данные.
