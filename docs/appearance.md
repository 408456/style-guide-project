# Внешний вид

Сайт имеет белый фон, темный текст, спокойные синие ссылки и один основной столбец. Не используем декоративные баннеры, эмодзи и анимацию. Основной размер текста - 17 px, межстрочный интервал - 1,65. Ссылки подчеркнуты. Таблицы имеют заголовки. Мобильная версия должна сохранять последовательность чтения; широкие таблицы прокручиваются внутри своего блока.
