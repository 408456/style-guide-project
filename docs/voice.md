# Стиль изложения

Обращаемся к читателю на вы. Пишем короткими предложениями и называем действие прямо: Выберите голос, затем нажмите Подтвердить. Один шаг содержит одно основное действие. Не пишем очевидно, просто и любой пользователь сможет. Не обещаем восстановить голос или гарантировать результат по любой записи. Пишем: Программа создает синтезированный голос на основе подходящих записей.
