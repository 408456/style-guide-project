# Назначение и аудитория

Руководство задает правила для документации ГолосЛичный. Пользователь читает инструкции по общению, помощник готовит записи, разработчик поддерживает программу. В начале каждой страницы указываем, кому она нужна и какое действие поможет выполнить. Документация описывает проектируемую первую версию. Названия экранов должны быть сверены с интерфейсом перед выпуском.
