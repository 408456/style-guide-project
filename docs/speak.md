# Как произнести сообщение

Инструкция предназначена для пользователя речевого коммуникатора. Перед началом должен быть настроен голос и включено устройство воспроизведения.

1. Откройте экран **Сообщение**.
2. Введите текст: Мне нужна вода.
3. Проверьте текст в области подтверждения.
4. Нажмите **Подтвердить и произнести**.

Результат: программа произносит подтвержденное сообщение один раз. При редактировании текста прежнее подтверждение сбрасывается.

Если звук не слышен, проверьте громкость и выбранное устройство. Повторное воспроизведение запускайте только после проверки текста.
