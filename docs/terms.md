# Термины

Персональный голос - настроенный вариант модели синтеза для одного пользователя. Речевой коммуникатор - программа, которая произносит введенный текст. Запись - исходный аудиофайл. Сообщение - текст, который пользователь готовит к произнесению. Адаптация - настройка готовой модели на предоставленных записях. Эти термины не заменяем словами клон, восстановленная речь или лечение.
