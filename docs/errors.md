# Сообщения об ошибках

Сообщаем, что произошло и что делать дальше. Плохо: Ошибка операции. Хорошо: Не удалось открыть запись. Выберите файл WAV или FLAC и повторите загрузку. Не обвиняем пользователя. Если результат не сохранен, пишем об этом явно. Технический код ошибки помещаем после понятного объяснения, если он помогает обратиться за поддержкой.
