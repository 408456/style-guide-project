# Как подготовить записи

Инструкция предназначена для пользователя и его помощника. Используйте записи, которые пользователь предоставил для настройки своего голоса. До передачи файлов подтвердите согласованные условия их использования.

1. Выберите записи, на которых говорит один человек.
2. Удалите фрагменты с музыкой, чужими голосами и сильным шумом.
3. Сохраните файлы в WAV или FLAC.
4. Добавьте точную текстовую расшифровку каждого фрагмента.
5. Передайте комплект через согласованное закрытое хранилище.

Результат: подготовлены аудиофайлы и соответствующие им расшифровки. Разработчик проверит пригодность записей до адаптации. Недостаточный объем или качество могут стать причиной отказа от настройки. Реальные записи не размещают в публичном GitHub.
